# MIAU — Diseño visual

Repositorio independiente para experimentar con la interfaz visual de MIAU sin modificar el proyecto funcional original.

## Tecnologías

- React
- Vite
- JavaScript
- CSS

## Instalación local

Requisitos: Node.js y npm.

```bash
npm install
npm run dev
```

Abre en el navegador la dirección local que indique Vite (normalmente http://localhost:5173).
